# STACKLY Tax & Compliance Advisory

**Tagline:** *Clarity in Compliance. Confidence in Every Decision.*

A static, GitHub Pages-ready corporate tax and regulatory compliance advisory web application built strictly with **HTML5**, **CSS3**, and **Vanilla JavaScript** (no backend runtime required).

## Design System
- **Primary:** Midnight Navy (`#14263D`)
- **Background:** Warm Ivory (`#F6F4EF`)
- **Accent:** Champagne Gold (`#B99A62`)
- **Typography:** `DM Serif Display` (editorial headings) + `Manrope` (UI & body text)
- **Motion Stack:** GSAP 3.14 + ScrollTrigger, AOS 2.3.4, and Lenis 1.3.11 smooth scrolling

## Pages Included
- `index.html` — Executive landing page with full-cover hero and 10 advisory sections
- `about.html` — Company overview, story timeline, mission & vision, values, leadership, methodology
- `services.html` — Complete practice overview covering Direct Tax, GST, Corporate Tax, Regulatory Compliance, Audit & Assurance, and Financial Advisory
- `industries.html` — Sector-focused desks across Startups, SMEs, Enterprises, Manufacturing, Technology, Healthcare & Professional Services
- `contact.html` — Regional offices (Bengaluru, Hyderabad, Chennai, Coimbatore), enquiry forms, consultation scheduling, and FAQs
- `service-details.html`, `consultation.html`, `insights.html`, `insight-details.html`
- `login.html` & `signup.html` — Validated role-based portal authentication (`Client` -> `ClientDashboard.html`, `Admin` -> `AdminDashboard.html`)
- `AdminDashboard.html` & `ClientDashboard.html` — Responsive Chart.js dashboards with 5-menu navy sidebars and interactive demo data
- `404.html` — Custom GitHub Pages error page with GSAP entrance, `Back`, and `Back to Home` controls

## GitHub Pages Deployment
All asset, CSS, and JavaScript paths are relative (`assets/...`, `css/...`, `js/...`), and every website image is encoded in `.webp` format inside `assets/`. Deploy directly from the repository root via GitHub Pages.
